## 🛡️ Project Overview
**ScamShield AI** is an ultra-fast, senior-friendly digital scam and phishing detection web application engineered specifically for Indian families and seniors. It analyzes suspicious SMS messages, WhatsApp forwards, phishing links, and coercion threats in Bengali, Hindi, and English within 3 seconds, delivering a high-contrast traffic-light verdict and plain-language protective advice.

### 🎯 Key Threat Detection Categories:
1. **Electricity Disconnection Scam:** False WBSEDCL/BSES power cutoff threats at 9:30 PM.
2. **India Post / Courier Address Hold:** Fake parcels requiring ₹25 redelivery fee to harvest cards.
3. **Bank KYC / Pan Card Block:** Impersonation of SBI/HDFC/ICICI net banking login portals.
4. **Work-from-Home Telegram Review Scam:** Fake ₹3,000-₹5,000/day YouTube like & Google review traps.
5. **Digital Arrest & Police Extortion:** Fabricated CBI/Customs/TRAI narcotics threats.
6. **UPI Reverse QR Code Scam:** Deceptive claims that scanning a QR code is required to receive lottery/cashback.
